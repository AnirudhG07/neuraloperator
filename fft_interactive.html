Cooley-Tukey FFT

Universal Butterfly Visualizer — any N ≤ 64

The Core Concept

The DFT converts a signal from time domain to frequency domain:

X[k] = ∑n=0N-1  x[n] · e−j(2π/N)nk

Computing directly is O(N²). For N=1024 that's over 1 million complex multiplications. FFT reduces this to O(N log N) — about 5,000 operations — by recursively exploiting mathematical symmetry.

Why Power of Two?

The Radix-2 algorithm requires N to be a power of two. If your signal has 10 samples, you zero-pad to N=16. Mixed-radix or Bluestein's algorithm handles arbitrary N.

Decimation in Time (DIT)
X[k] = E[k] + WNk·O[k]

Periodicity Trick: WNk+N/2 = −WNk, so X[k+N/2] = E[k] − WNk·O[k]. Both outputs from one multiply.

The Butterfly Unit
t = WNk · b
outtop = a + t
outbot = a − t

How this hardware works: There is one physical PE-A block and one SRAM bank pair (ping-pong). Data loops back from the PE-A output into the SRAM, and gets read again on the next pass with a shuffled address. The loop runs ⌈log₂N / 2⌉ times. Only W_base register changes between loops.

PE-A + PE-B — Hardware Loop-Back Architecture
Length: 8N: 8
How this hardware works: There is one PE-A and one PE-B block, always used as a fixed pair. Data goes: SRAM → PE-A → PE-B → SRAM (one full loop = 2 stages). The loop repeats ⌈log₂N / 2⌉ times. Each loop, data re-enters PE-A from scratch — the full PE-A → PE-B path is always traversed together.
